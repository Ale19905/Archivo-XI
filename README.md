# Archivo XI — proyecto HTML + CSS

Sitio académico de cinco vistas construido únicamente con HTML y CSS:

- `index.html` — Inicio
- `nosotros.html` — Sobre nosotros
- `productos.html` — Productos / galería
- `contacto.html` — Contacto
- `login.html` — Iniciar sesión
- `estilos.css` — Hoja de estilos compartida

## Requisitos cubiertos

- Header y navegación comunes con Flexbox.
- Estructura semántica completa.
- Metaetiquetas SEO básicas.
- Diseño responsive.
- Tema claro/oscuro mediante `prefers-color-scheme`.
- Animación de entrada discreta en el hero del inicio.
- Página “Nosotros” en CSS Grid, con imagen y lista.
- Galería con tarjetas, imágenes y transición `hover`.
- Tabla comparativa en productos.
- Formulario de contacto con tipos de campos distintos y validación HTML5.
- Vista de inicio de sesión con usuario/correo, contraseña, “Recordarme”, recuperación y registro.
- Sin JavaScript.

## Uso

Abrir `index.html` en el navegador. No requiere instalación ni servidor para la maqueta básica.
